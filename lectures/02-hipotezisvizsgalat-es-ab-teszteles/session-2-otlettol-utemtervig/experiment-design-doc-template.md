# Kísérletterv-dokumentum — sablon

Csoportonként **2-3 másolat** kell (egy-egy a kiválasztott ötleteitekre).
Minden becsült számnál tegyétek fel: *honnan ez a szám — megérzés, vagy a
mai kalibrációs adatokhoz (Streaks: 100% elérés / +0,6pp; Puzzle v2: 10%
elérés / +5,0pp) viszonyított, védhető becslés?*

---

## Ötlet neve

**Funkcióterület**: Matchmaking / Tartalom / Tréning / Oktatás *(válassz
egyet)*

**Hipotézis**: *Mit vártok a változtatástól, és miért? Egy mondat.*

**Becsült elért létszám (reach)**: _____ fő/nap
*(induljatok ki a `business-case.md` DAU-bontásából — melyik funkcióterület
napi aktív létszámát érinti az ötlet?)*

— ennek a teljes web DAU (200 000) hány %-a? _____ %

**Becsült hatás**:
- Kontroll (jelenlegi, becsült alapérték): _____ %
- Treatment (becsült, a változtatással): _____ %
- Abszolút különbség (pp): _____ pp
- Relatív lift: _____ % *(legyetek konzervatívak — a Puzzle v2 +9,1%-a volt
  a mai nap "nagy" száma egy élesben futó kísérletnél)*

**Fejlesztői ráfordítás**: S (1-2 hét) / M (3-5 hét) / L (6-8 hét)
*(karikázzátok be)*

**Számolt nettó konverzió / DAU**:

$$\text{elért létszám} \times \text{abszolút lift (pp)} \; / \; 200\,000 = \_\_\_\_\_\%$$

**Pontszám** (nettó konverzió/DAU ÷ fejlesztői ráfordítás hétben):

$$\_\_\_\_\_\% \; / \; \_\_\_\_\_ \text{ hét} = \_\_\_\_\_$$

**Kockázat / megjegyzés**: *Mi az, ami ha nem jön be, a legjobban
felborítja ezt a becslést? (pl. a reach-becslés túl optimista, a hatás
csak rövid távon jelentkezik, stb.)*
