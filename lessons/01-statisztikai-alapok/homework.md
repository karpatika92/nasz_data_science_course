Két rész: (1) videók + rövid reflexió, (2) GitHub + AI kódoló ügynök beüzemelése.
Mindkettő kötelező, mindkettő beadandó a következő óra előtt.

## 1. rész — Videók + reflexió

Az órán érintett témák közül nyolchoz találtam **ellenőrzött, valódi** videót —
mindegyiket megnéztem/megkerestem, nem tippeltem linket. A nagy számok törvényéhez
és a dimenzió-átokhoz **nem** találtam elég jó, azonosítható forrású videót ezekről a
csatornákról, ezért oda nincs kötelező videó — az órai `demo.ipynb` szimuláció ott
elég.

**Megjegyzés:** csak a Monty Hall, a Bayes-tétel és a CLT videója jön a kért három

## 2. rész — GitHub + AI kódoló ügynök beüzemelése

Ezt a kurzus egészéhez fogjuk használni — a projektmunkát is git repóban adjátok
majd le, és a féléves anyagot is GitHub-on osztjuk meg.

**Lépések:**
1. Regisztrálj egy GitHub fiókot, ha még nincs (https://github.com).
2. Hozz létre egy **saját, publikus repót** (pl. `<neved>-data-science-kurzus`
   néven) — ez lesz a te munkaterületed a félév során.
3. Telepíts/kapcsolj be egy **AI kódoló ügynököt** tetszés szerint (pl. GitHub
   Copilot, Claude Code, Cursor, Windsurf — bármelyik jó, aminek van ingyenes vagy
   diák-előfizetése).
4. **Bizonyíték a beüzemelésre:** kérd meg az AI ügynököt, hogy hozzon létre a
   repódban egy `README.md`-t, ami röviden leírja, ki vagy és mit vársz a
   kurzustól — majd **commitold és pushold** ezt a változtatást. A következő órán
   ennek a repónak a linkjét kérem.

*(Miért fontos ez már most? A projektmunkát is verziókövetéssel adjátok majd le, és
minél korábban hozzászoktok az AI-asszisztált munkafolyamathoz, annál gyorsabban
haladtok majd a nehezebb anyagon.)*
